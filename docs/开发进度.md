**B01：环境与基础框架**

状态：已完成本批实现及模拟器验证。完成日期：2026-09-09。

用户授权范围：搭建环境与基础框架，连接模拟器，仅包含基础 UI、路由和网络请求库。未扩展到登录、业务表单或 AI。

**本批交付**

- 项目专用 JDK 17.0.20.1、Gradle 8.13、Android SDK 36、Build Tools 35.0.0、Platform Tools。
- 官方 Gradle Wrapper，配置发行包 SHA-256；插件/依赖版本统一放版本目录。
- app 单模块，Kotlin 2.2.20 + Compose + Material 3，浅色/深色主题。
- 首页、业务、助手、任务、我的五个导航入口，以及开发用连接检查子路由。
- Retrofit 3.0.0、OkHttp 4.12.0、Serialization 1.9.0；仅 GET /health，具备输入检查、超时和错误反馈，无账号/正文日志。
- WSL 环境脚本、构建入口、模拟器启动及安装脚本；独立 Git 仓库与工具/密钥/产物忽略规则。
- 7 个手写 Kotlin 文件（含 2 个测试文件），合计 394 行；工程配置、XML、脚本与官方 Wrapper 另计，属于初始化批次。

**设备与环境处理**

- 最终设备：官方 `CityBond_API_30`，ADB 序列号 `emulator-5558`，Android 11 / API 30，720 × 1280。
- Windows 腾讯模拟器的正常 ADB 连接未成功，最终使用项目内官方模拟器。
- 排查初期沙箱中看不到 /dev/kvm；实际 WSL 中设备已存在，主要问题是用户组权限。
- 经批准通过 WSL 管理员将 `tdy` 加入 `kvm` 组，最终已启用 KVM 硬件加速；启动脚本支持现有终端通过 sg 应用组权限。
- 模拟器运行库解压在项目工具目录；未全局安装 Ubuntu 软件包，未修改 Windows 虚拟化功能。
- 本机 IDE 工作方式为 VS Code/WSL 终端；未安装 Android Studio IDE。
